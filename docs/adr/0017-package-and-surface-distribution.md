# ADR 0017: Package and surface distribution

## Status

Deferred.

## Context

The repository is private to npm and its current owner/repository coordinates do not match the
brief's illustrative action name. Distribution choices constrain CLI, MCP, and Action references.

## Decision

Deferred, not decided: public npm ownership and GitHub Action coordinates remain open.

## Consequences

No public package or action reference may be promised until ownership and coordinates are
confirmed. Distribution implementation remains outside Phase 1 Slice 1.
